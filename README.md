# Lecture Notes on Scattering Amplitudes

This repository collects lecture notes on modern scattering amplitudes and related topics in quantum field theory, string theory, and cosmology.

The notes provide concise introductions to several important ideas and active research directions in the modern amplitudes program.

## Topics Covered

The collection includes material on:

- string amplitudes and surfaceology;
- scattering amplitudes and correlators in AdS/dS;
- amplitudes in \(\mathcal{N}=4\) supersymmetric Yang–Mills theory;
- positive geometry and bootstrap methods;
- scattering equations and CHY/worldsheet formulations;
- analyticity, unitarity, crossing symmetry, and the S-matrix bootstrap.

## About the Notes

These notes are intended for students and researchers interested in modern methods for studying scattering amplitudes. Some notes are introductory, while others focus on more specialized or research-level topics.

The collection will be updated and expanded over time.
